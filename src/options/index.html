Qwen Browser Agent

Ollama

Ollama must allow this extension as an origin. Set OLLAMA_ORIGINS to chrome-extension://* before starting it — see the README for the exact command on Windows and macOS.

Generation

Ollama caps context at 4096 unless this is set, which quietly truncates long pages. 64k suits a 32 GB card; lower it if the model spills out of VRAM.

Qwen3.8 ships at the highest effort and overthinks routine steps.

Ollama unloads after 5 minutes idle, which makes the next question slow to start.

Pages and tasks

0 sizes it from the context window (about 147,000 characters at 64k), so a whole long page reaches the model. Set a number only if you want a hard cap.

Only used if the model reports image support.

Strongly recommended. An unanswered prompt is declined after a minute. Separately, and not switchable, a task is fenced to the site it started on plus any site you name in the task, and the agent never types into password or payment fields.
